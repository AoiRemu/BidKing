## 低保系统详解

```
触发条件: 总资产 < 100,000
领取次数: 每天3次
每次金额: 100,000 银币

总资产计算:
  普通货币总价
+ 仓库所有藏品总价值（含绑定物品，按卖店价）
+ 收藏柜藏品总价值（按卖店价）
```

**策略：如果资产接近10万，可以故意出售藏品降到门槛以下，领取低保后再买回来。**

## 返利系统

```
bid_fanli:
  条件: 结算时亏损 > 10,000
  返利: 亏损额 × 千分之100 = 10%
  参与方: 所有参与玩家（弃权者不算）
```

**策略：可以适度承受小额亏损来博弈大额利润。如果亏15000，返1500，净亏13500——可接受。**

## 交易行系统

```
解锁条件: 收藏等级 ≥ 25 (bid_lv)
拍卖周期: 24/48/72小时可选
公示期: 24小时
上架费: 起拍价 × 万分之100 (1%)
保管费: 万分之1000
税率: 万分之1000
栏位基础: 5个（最多10个）
栏位购买: 50/100/150/200/300 (递增)
出价次数上限: 100次
出价增量: 万分之500 (0.05%)

反狙击机制:
  公示期最后600秒内有人出价 → 延长600秒
```

## 资产增长路径

### 阶段一：原始积累 (0 → 100K)
- 领低保（每天3次×10万）
- 打快递场，专拍2001+低竞争品
- 完成新手任务

### 阶段二：稳步增长 (100K → 500K)
- 主打仓库场+集装箱场
- 每局预算控制在总资产20%以内
- 开始买2500档道具（十方窥视+类型鉴影）

### 阶段三：规模化 (500K → 2M)
- 主打别墅场（2401首选，拉文多）
- 每局预算30-50万
- 专攻AI三重盲区藏品

### 阶段四：财富自由 (2M+)
- 别墅+残骸场
- 每次竞拍5-10件高价值藏品
- 解锁交易行，出售多余藏品
