# 实战策略与操作手册

## 快速决策流程

```
进入竞拍前:
├── 选地图: 查拉文权重 → 越高越好
├── 选英雄: T0法蒂玛/索菲/加布里埃拉/艾哈迈德
├── 买道具: 2500档×2-4个（十方窥视+对应类型鉴影）
└── 确认预算: 入场费+道具+竞拍=总预算

第1回合（信息收集）:
├── 英雄技能自动揭示信息 → 读取
├── 使用道具补充关键信息
├── 判断本场: 有金/红色吗？数量多少？
├── 出价决策: 只对低竞争目标出底价
└── 观察AI行为: 哪些AI在竞争哪些物品

第2-3回合（精准竞拍）:
├── AI中期活跃 → 让他们互相消耗
├── 对三重盲区目标出价（类型106-110+大件+高价值）
├── 出价 = 估值×50-70%
└── 不要追高AI关注的小件

第4-5回合（收割）:
├── AI预算接近耗尽
├── 对所有剩余盲区物品出底价
├── 每轮+0.05%最低增幅
└── 计算本局利润
```

## 出价公式

### 保守出价（推荐）
```
出价 = 估值 × 60%
估值来源: 英雄技能 + 道具揭示 + 同类型同品质同形状对比
```

### 估值推算方法

当你知道部分信息时可以推算：

**已知品质+类型+形状：**
- 在同品质同类型的藏品中找形状接近的 → 取中位数价值 → ×60% 出价

**已知品质+形状（未知类型）：**
- 该品质所有藏品平均价值 → 刨除低价值类型(101-105) → ×50% 出价

**只知道品质（未知类型+形状）：**
- 白品质: 出价 < 200
- 绿品质: 出价 < 500
- 蓝品质: 出价 < 1500
- 紫品质: 出价 < 5000
- 金品质: 出价 < 25000
- 红品质: 出价 < 50000

## 风险控制

### 什么时候弃权
- 本场没有你的目标类型(106-110)
- AI都有高预算(等级1-2)，竞争太激烈
- 前2轮没有揭示任何金/红色藏品
- 当前亏损已超过可用资金20%

### 止损线
```
单局最大亏损: 总资金 × 5%
单局最大出价: 总资金 × 15%
单件最大出价: 总资金 × 5%
```

### 资金管理
- 永远不要 ALL IN 在一件藏品上
- 拍卖场次间保持 ≥ 5 万流动资金
- 如果连续3局亏损，降级到低一级场地

## AI 对手侦察

通过以下方式判断 AI 等级：

1. **看 AI 出价频率**：等级1-2频繁出价，等级5-6几乎不出价
2. **看 AI 出价幅度**：等级1-2出价高（接近物品价值），等级5-6出价极低
3. **看 AI 英雄选择**：拉文(301)出现 = 弱AI
4. **看物品竞争程度**：AI关注的小件(1-2格，价值701-1500)如果没人抢 = 可能是高等级AI（预算0）

如果在某地图发现 AI 基本不出价 → 说明你匹配到了高等级 AI → 那就是刷钱圣地。
