## 道具使用策略

### 低成本组合（总花费 < 10000）
```
十方窥视 (2500) + 古董鉴影 (2500) + 宝光四鉴 (1000) = 6000
```
先看古董类轮廓 → 再随机看4件品质 → 交叉对比锁定目标

### 信息叠加策略
```
普品扫描(500) + 良品扫描(1000) + 优品扫描(2500) = 4000
```
排除白→绿→蓝品质后，剩余 = 紫+金+红约295件高价值藏品

### 最优性价比组合
```
按地图主题选对应的类型鉴影(2500) + 十方窥视(2500) = 5000
```
精准看到你关注类型的所有轮廓 + 10件随机轮廓作为补充信息
