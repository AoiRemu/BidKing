# 竞价之王 (BidKing) 完全攻略

## 游戏概述

竞价之王是一个 2-4 人竞拍博弈游戏。每局 5-20 轮，玩家对"盲盒"藏品出价。藏品在被揭示前部分信息隐藏（轮廓/形状、品质、类型、价值）。英雄技能和道具可以揭示隐藏信息。

**核心目标：以低于真实价值的价格拍下藏品，最大化利润。**

**利润公式：`利润 = 藏品真实价值 - 出价 - 2000税费`**

## 游戏系统架构

```
竞拍系统
├── 英雄系统 (20个英雄，每周5个免费)
├── 道具系统 (63个技能道具)
├── 地图系统 (5个等级 × 10个主题 = 50个地图)
├── AI系统 (120个AI配置，6个等级 × 20个英雄类型)
├── 经济系统 (货币/税收/返利/低保/利息)
├── 仓库系统 (50格基础，10个仓库上限)
├── 收藏柜系统 (11个品类柜)
├── 交易行系统 (收藏等级≥25解锁)
├── 排位系统 (6个段位)
├── 协会系统 (公会)
├── 通行证系统
└── 模拟模式
```
